फ़ाइल मैनेजर — पूरा GitHub Repo
यह आपके repo में अभी जो भी है (हर फ़ोल्डर, हर फ़ाइल — index.html, sabadwani-data.json, audio/, images सब) सीधे GitHub से दिखाता है। यहाँ से आप किसी भी फ़ाइल को खोल/एडिट/डिलीट कर सकते हैं, या नई फ़ाइल (जैसे ऑडियो/इमेज) किसी भी फ़ोल्डर में अपलोड कर सकते हैं।
यह टेक्स्ट फ़ाइल नहीं है (जैसे ऑडियो/इमेज) — इसे यहाँ एडिट नहीं किया जा सकता, सिर्फ़ देख/डाउनलोड/डिलीट कर सकते हैं। बदलने के लिए नई फ़ाइल उसी नाम से अपलोड करें (नीचे "अपलोड करें" सेक्शन)।
डाउनलोड
नई फ़ाइल अपलोड करें (ऑडियो / इमेज / कोई भी)
बड़ी ऑडियो फ़ाइलें (~15MB से ज़्यादा) GitHub API से सीधे अपलोड नहीं होतीं — उतनी बड़ी फ़ाइल के लिए पहले उसे compress/MP3 (128kbps) कर लें।
index.html — लाइव कोड एडिटर
यह आपके repo की असली index.html फ़ाइल है। "GitHub से लाएं" दबाकर मौजूदा लाइव कोड यहाँ खोलें, नीचे सीधे बदलाव करें, फिर "बदलाव Publish करें" दबाकर उसी फ़ाइल में वापस भेज दें — कोई डाउनलोड-अपलोड नहीं। अगर आप कुछ भी एडिट नहीं करना चाहते और सिर्फ़ ऐप का नवीनतम बिल्ट-इन वर्ज़न repo में डालना चाहते हैं, तो सीधे "नवीनतम टेम्पलेट भरें" के बाद Publish करें।
सावधानी से एडिट करें — यह ऐप की पूरी सोर्स फ़ाइल है। कुछ भी टूट जाए तो "नवीनतम टेम्पलेट भरें" दबाकर सुरक्षित वर्ज़न पर वापस आ सकते हैं।
